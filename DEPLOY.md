# Chatsplat — Deploy Guide

## 1. Backend on Render (recommended)

### One-click setup
1. Go to **render.com** → New → Blueprint
2. Connect `hex615/hex615` repo — Render reads `render.yaml` automatically
3. It creates: API server + PostgreSQL + Redis in one shot
4. After first deploy, open the Render shell and run:
   ```
   npm run migrate
   ```

### Set these env vars in Render dashboard (Settings → Environment)
| Variable | Where to get it |
|---|---|
| `AGORA_APP_ID` | console.agora.io → Project → App ID |
| `AGORA_APP_CERTIFICATE` | console.agora.io → Project → Certificate |
| `TWILIO_ACCOUNT_SID` | console.twilio.com |
| `TWILIO_AUTH_TOKEN` | console.twilio.com |
| `TWILIO_PHONE` | Your Twilio number e.g. +12015551234 |
| `CLOUDINARY_CLOUD_NAME` | cloudinary.com dashboard |
| `CLOUDINARY_API_KEY` | cloudinary.com dashboard |
| `CLOUDINARY_API_SECRET` | cloudinary.com dashboard |
| `OPENAI_API_KEY` | platform.openai.com |
| `FCM_SERVICE_ACCOUNT_JSON` | Firebase console → Service accounts → Generate key |
| `ALLOWED_ORIGINS` | Your app's bundle ID scheme or web URL |

`JWT_SECRET` and `JWT_REFRESH_SECRET` are auto-generated by Render (`generateValue: true`).

### Enable Twilio OTP
In `backend/src/routes/auth.js`, uncomment the Twilio block:
```js
const tw = require('twilio')(process.env.TWILIO_ACCOUNT_SID, process.env.TWILIO_AUTH_TOKEN);
await tw.messages.create({ body: `Your Chatsplat code: ${code}`, from: process.env.TWILIO_PHONE, to: phone });
```

## 2. Backend on Railway

1. **railway.app** → New Project → Deploy from GitHub
2. Add **PostgreSQL** plugin → copy `DATABASE_URL` to Variables
3. Add **Redis** plugin → copy `REDIS_URL` to Variables
4. Set all other env vars (same table above)
5. Railway reads `railway.toml` automatically
6. After first deploy, open Railway shell: `npm run migrate`

---

## 3. Mobile App Build

### Prerequisites
```bash
npm install -g eas-cli
cd mobile
eas login          # free expo.dev account
```

### Before building — update eas.json
Replace `https://api.chatsplat.app` with your actual Render/Railway URL.
Replace `YOUR_AGORA_APP_ID` with your real Agora App ID.

### Android APK (no store account needed for testing)
```bash
eas build --platform android --profile preview
```

### Android Play Store (AAB)
```bash
eas build --platform android --profile production
eas submit --platform android
```

### iOS (requires $99/yr Apple Developer account)
```bash
eas build --platform ios --profile production
eas submit --platform ios
```

## 4. Agora Setup

1. Create account at **console.agora.io**
2. Create a new project → enable **App Certificate**
3. Copy **App ID** → set as `AGORA_APP_ID` in backend env + `EXPO_PUBLIC_AGORA_APP_ID` in eas.json
4. Copy **App Certificate** → set as `AGORA_APP_CERTIFICATE` in backend env

The backend auto-generates channel tokens via the `/rooms/:id/agora-token` endpoint.
